  \caption{Steady ML-step timings for standalone and clustered SmartSim
    deployments. Columns show the mean across five runs; error bars indicate
    two-sided 95\% Student-$t$ confidence intervals for the run mean.
    Each run is averaged over 96 solver ranks and 50 steady ML steps,
    excluding the initial warmup step. All timings use inclusive Score-P
    regions from the same steady-step subtree. The total is the profiled
    rank-mean step duration, not the synchronized solver walltime.
    \texttt{put\_tensor} includes both input uploads per step;
    \texttt{run\_model} measures the client-observed synchronous call,
    including communication and server execution.}
  \label{fig:smartsim-runtime-regions}
